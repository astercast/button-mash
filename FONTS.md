# PortPlay fonts — provenance (PP1)

All faces are self-hosted from assets/fonts/. No page makes a remote
font request. All three families are licensed under the SIL Open Font
License 1.1.

- Barlow (400, 500, 600, 700), latin subset woff2 — Jeremy Tribby,
  via Google Fonts (barlow v13). Files: barlow-*-latin.woff2.
- Barlow Condensed (600, 700), latin subset woff2 — Jeremy Tribby,
  via Google Fonts (barlowcondensed v13). Files:
  barlow-condensed-*-latin.woff2.
- Martian Mono (400-500 variable), latin subset woff2 — Roman
  Shamin / Evil Martians, via Google Fonts (martianmono v6). File:
  martian-mono-400-latin.woff2 (the variable file serves both
  weights; declared with a 400 500 range in tokens.css).

Downloaded 2026-10-23 for "The Appliance" build (Rotation 139).
The previous faces (Sora, Inter) are no longer the site's voices;
their preloads are removed from every page.
