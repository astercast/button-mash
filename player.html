Centerpiece 01

The Player. Bring your own file.

Twenty-plus classic systems, one browser tab. Drop in a game file you own — it never leaves your machine — and play with keyboard, gamepad, touch controls, save states and fullscreen. Powered by the open-source EmulatorJS engine.

IDLE — DROP A FILE TO BEGIN
📥

Drop your game file here

…or use the buttons below. Your file is read locally in your browser — it is never uploaded anywhere. Button Mash hosts zero ROMs and provides zero game files.

Tip: the in-game menu (top-left icon once booted) has save states, controls remapping, shaders and cheats.
🛡️ Legal lane: the Player is a bring-your-own-file tool. Only load game files you own (dumps of cartridges/discs you physically own, homebrew, or public-domain releases). Read the rules · How to rip your own cartridges

▸ How to play

1️⃣

Load your file

Drag & drop, pick from your device, or paste a direct download URL (the host must allow cross-origin fetches — if a URL fails, download it and drop it in). The system is auto-detected from the file extension; override it with the dropdown if needed.

2️⃣

Control it your way

Keyboard works out of the box — arrow keys and the usual suspects cover most games; open the in-game menu → Controls to see the exact mapping and remap everything. USB gamepads are supported, and touch devices get on-screen buttons automatically.

3️⃣

Save like it's 1999 (but better)

Save states live in the in-game menu and persist in this browser via local storage. In-game saves (SRAM) work too. Ejecting swaps the cartridge — your states stay put.
