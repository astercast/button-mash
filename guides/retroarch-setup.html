RetroArch setup guide

Install RetroArch, add cores for hardware you own, and load your own dumped games — controllers, save states, shaders, and netplay included.

  • ⏱ ~20 min
  • Beginner
Legal lane: this guide covers tools and techniques only. Supply ROMs you dumped from games you own, plus homebrew and public-domain titles. No ROM download links, no piracy sites — ever.

What it is (and the legal line)

RetroArch is a free, open-source frontend for emulators. Instead of one emulator per system, you install RetroArch once and add small emulator modules called cores — one for each console you want to play. It runs on Windows, macOS, Linux, Android, iOS, and even in a browser.

RetroArch contains no games and no BIOS files. You bring those: dumps of games you own (see the rip-your-own guide) and homebrew or public-domain titles.

1. Install RetroArch

Download RetroArch from retroarch.com — pick your platform. It's also on Steam and most package managers, which handle updates for you. Install it like any normal app; the first launch walks you through the basics.

2. Download cores (the emulators)

Go to Main Menu → Online Updater → Core Downloader. You'll see a list of cores, each named for the hardware it emulates. Install the core matching hardware you own — for example, a Game Boy Advance core if you have GBA cartridges to dump.

Cores are emulator software, and they're legal. Installing ten cores you never use harms nothing; loading a game you don't own into one is the part that's piracy.

3. Load your own games

Main Menu → Load Content → browse to your dumped ROM file. RetroArch will ask which core to use; pick the one you installed. To build a pretty library view, use Import Content → Scan Directory on a folder of your dumps — RetroArch matches them against its database and builds per-system playlists with box art.

4. Controllers

Settings → Input. Most USB and Bluetooth gamepads are recognized automatically with sane default mappings — plug in and play. If a button feels wrong, remap it per-core under Quick Menu → Controls while a game is running; RetroArch saves the remap for that core.

5. The good stuff: saves, shaders, netplay

  • Save states: Quick Menu → Save State, with slots per game
  • Rewind: enable it in Settings → Frame Throttle, then hold the rewind hotkey to scrub mistakes away
  • Shaders: Quick Menu → Shaders adds CRT scanlines and other retro looks
  • Netplay: Netplay menu for online multiplayer on supported cores
  • Achievements: sign up at retroachievements.org and link it in Settings for retro achievements

The rule, one more time

Keep your library to three sources: dumps of games you own, homebrew from its authors, and public-domain releases. RetroArch never asks where your files came from — that's your responsibility, and it's the whole difference between a legal retro setup and a piracy box.
