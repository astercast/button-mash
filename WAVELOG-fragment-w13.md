## Design findings applied (web-craft domain input)
The coordinator's round-1 design report was still in flight when this wave ran, so these are applied from established craft practice, each chosen for a long-form reading context and kept inside the site's neon-arcade identity (no redesign):
1. **Guide page architecture** — proper breadcrumb trails, sticky TOC with scroll-spy, dense cross-linking between guides (every new guide links siblings inline + "More guides" lists), hub section on emulation.html.
2. **Long-form typography** — 65ch measure, 1.75 line-height, pretty/balanced text wrapping, section dividers with mono numerals, key-point callouts, print stylesheet.
3. **Scroll-driven animation** — CSS-only reading progress bar via scroll timelines (progressive enhancement; user-driven, so reduced-motion-safe).
4. **View transitions** — cross-document `@view-transition` for a subtle page-change fade on Chromium, strictly gated behind `prefers-reduced-motion: no-preference`.
5. **Deliberately skipped:** scroll-triggered reveal animations (decoration that adds nothing to reading; risk under reduced-motion), SPA-style transitions (MPA site; the at-rule covers the genuine elevation), drop caps / editorial restyling (would fight the arcade identity).
