▸ The tech: how GBA games run in browsers

The classic handheld generation — GBA included — can now run at full speed inside a browser tab. Two patterns make it possible:

  1. Interpreted cores in WebAssembly (what the Player uses): an emulator core like mGBA, compiled to WASM, interprets the original machine code instruction by instruction. Accurate, portable, and fast enough on modern hardware.
  2. Hybrid recompilation: experimental projects lift the game's ARM/THUMB machine code into real WebAssembly ahead of time, so ~99% of instructions execute as native WASM instead of being interpreted.

Both patterns share one rule: the game file comes from you. The engine is software; your ROM is your property.

Read the full explainer →

Source & inspiration: the experimental project gba-pokemon-rom-to-wasm demonstrates the hybrid recompiler pattern — ARM/THUMB basic blocks lifted into WebAssembly modules executed in-process, with differential verification against an interpreter. It ships no commercial ROMs; users supply their own. Our explainer is written from scratch; the repo is linked as the source.
