Your ROMs in. Browser games out.

Drop in Game Boy Advance, Game Boy / Game Boy Color, NES, Super Nintendo, or Sega Genesis files you own — one or a whole batch — → get back self-contained .html games: each ROM embedded inside, booting straight into play, hostable on any static host. Everything happens in your browser — your files never upload anywhere.

Drop your ROM files

Dumps of cartridges you own, homebrew files, or any ROMs you have the rights to — .gba (Game Boy Advance), .gb/.gbc (Game Boy / Color), .nes (NES), .sfc/.smc (Super Nintendo) or .md/.gen (Sega Genesis). Drop one file or a whole folder's worth: each becomes its own game, converted one at a time. Max size follows the real hardware: 32MB for GBA, 8MB for GB/GBC, 4MB for NES, 6MB for SNES, 4MB for Genesis.

    Play & share the files

    Double-click a downloaded .html to play instantly. Host it on any static host (GitHub Pages, itch.io, your own site) and it boots straight into your game — no installer, no emulator setup for the player. Each game also carries a ▶ Player mode button that re-opens it in the Button Mash Player (right system pre-selected) — handy on slow connections, since the Player streams your original ROM straight from disk.

    How it works, honestly: your exported game contains your ROM plus a player stub. The emulator engine (EmulatorJS) loads from its public CDN on first run, then it's cached by the browser. So the file needs internet the very first time — after that it plays from cache. Save states persist in the browser via local storage.

    🛡️ Legal lane: only convert files you own — dumps of cartridges you physically own, homebrew, or public-domain releases. Don't convert (or share) ROMs of games you don't own. Read the rules · How to dump your own cartridges

    » Engineering notes

    Size limits, stated plainly

    Caps follow the real hardware: 32MB for GBA, 8MB for GB/GBC, 4MB for NES, 6MB for SNES (48 Mbit — the biggest real carts), 4MB for Genesis (32 Mbit of directly addressable ROM space; bank-switched carts are exotic — use Player mode for those). Uncompressed base64 adds ~33% overhead; the compression option shrinks that substantially. We warn well below the cap — for big files, Player mode (no embedding, streams from your disk) is the better experience. Batches over 100MB of input get a memory heads-up: your browser holds it all while converting.

    We check your file — humbly

    Every file gets validated before conversion: empty files, all-zero dumps, and NES files missing the NES signature are refused with a plain-language reason. A blank cartridge header only earns a warning — many homebrew ROMs look like that and boot fine. GB/GBC header checksums are verified arithmetically; Genesis ROMs are checked for the SEGA header string (missing only warns — emulators don't enforce it); SNES copier headers are detected and kept as-is. One bad file never stops the rest of the batch.

    No BIOS needed — for all five

    All five export cores boot with zero extra files: mGBA ships its own built-in BIOS replacement, and Gambatte (GB/GBC), FCEUmm (NES), Snes9x (SNES) plus Genesis Plus GX (Genesis cartridges) need no BIOS at all. Your game boots the moment it loads. Save states and in-game saves persist in the player's browser via local storage.
