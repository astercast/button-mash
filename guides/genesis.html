Genesis emulation guide

The blast-processing years: a flawless core, zero BIOS files, and the fastest, punchiest 16-bit action library. Also the cheapest system to emulate — if it has a browser, it runs Genesis.

1. The core: Genesis Plus GX

The Player's segaMD core is Genesis Plus GX — the default backend for Genesis/Mega Drive (plus Game Gear and Sega CD) in the official EmulatorJS core list, where it's widely considered the accuracy standard for Sega's 16-bit hardware. The same core also powers the Player's Game Gear emulation under segaGG.

The Player detects .md, .gen, and .smd files and boots Genesis Plus GX automatically.

2. BIOS notes (the short version: none)

Genesis cartridges are self-contained — nothing to dump, nothing to attach. (Only the Sega CD add-on, a separate segaCD core, needs a BIOS dumped from your own hardware — that's why the Player flags it.)

3. Settings that matter

Open the engine's in-game menu (the ⚙ icon) while a Genesis game is running:

  • Region: games ran at slightly different speeds in different regions; the core auto-detects, but if a game feels off-speed or shows region warnings, force the matching region manually.
  • Controller type (6-button pad): later games used the six-button controller — make sure the core is set to it for those titles, or you'll be missing buttons.
  • SRAM autosave: the engine persists cartridge saves automatically; make sure autosave is on so progress survives a closed tab.
  • Audio low-pass filter: tames the Genesis's famously harsh FM sound into something closer to a real console on real speakers — worth toggling.

4. Performance: runs on a toaster

Genesis is the lightest console core in the Player — 1988 hardware with a 7.6 MHz CPU. Anything that runs a modern browser runs it at full speed, phones and old Chromebooks included. If it ever stutters, the cause is the browser (power saving, tab overload), never the core.

5. Saves & cheats in the Player

  • Save states — instant snapshots from the in-game menu; export/import/delete them with the Player 2.0 Save tool on player.html when Keep in Browser is on (Settings → Save States).
  • In-game saves — SRAM battery saves persist automatically.
  • Cheats — the Player 2.0 Cheats tool takes Game Genie codes, stored per game and injected before boot; toggle in the engine's cheat manager.
  • Keyboard remap — the Player 2.0 Controls tool remaps Player 1's keyboard and gamepad bindings (applies on next boot).

8. Native alternative: RetroArch

The same Genesis Plus GX core runs inside RetroArch (retroarch.com) — see the RetroArch setup guide. Desktop wins on shaders, run-ahead latency reduction, and netplay; the browser Player wins on zero setup.
