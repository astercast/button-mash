The Player. Bring your own file.

Twenty-plus classic systems, one browser tab. Drop in a game file you own — it never leaves your machine — and play with keyboard, gamepad, touch controls, save states and fullscreen. Powered by the open-source EmulatorJS engine.

Drop your game file here

…or use the buttons below. Your file is read locally in your browser — it is never uploaded anywhere. Button Mash hosts zero ROMs and provides zero game files.

» Player 2.1 tools

Client-side upgrades. Everything below runs in your browser — your files, saves and settings never leave your machine.

💾 Save slots

Named save slots for the current (or most recent) game, kept in this browser's storage — the same place the engine's Keep in Browser mode uses. Save copies the engine slot into a named slot; Restore copies it back so the engine's Load State picks it up. Slots are browser-local — export the file to move one to another device.

Boot a game above to manage its save slots.
    ⏱ Auto-save

    Import writes the file into browser storage under the current game's name, so the engine's Load State picks it up. State files are tied to the emulator build — a file from a much newer/older engine may not load. Auto-save copies the engine slot on a timer while this tab stays open, and only works in Keep in Browser mode (in-game menu → Settings → Save States).

    🎮 Controls — per-system remap

    Player 1's keyboard and gamepad bindings, one map per system — remap GBA once and every GBA game uses it. Click Remap key, then press a key (Esc cancels); click Remap pad, then press a gamepad button (Esc cancels). Saved maps apply the next time a game for that system boots. The remapper itself is fully keyboard-operable.

    Pick a system to see its mappings.
    ButtonKeyboardGamepadRemap

    This per-system map overrides Player 1 changes made in the engine's own Control Settings on next boot — use this panel for Player 1. Analog-stick axes can only be remapped in the engine's own Control Settings (gamepad icon in the in-game menu). Your older per-game mappings were moved into the per-system map automatically.

    ✨ Cheats

    Enter your own cheat codes for the current game. They're loaded into the engine's cheat manager when the game boots — toggle them on/off with the cheat icon in the in-game menu. Use codes you trust, for games you own.

    Boot a game above to attach cheats to it.

      Code formats (Game Genie / GameShark / Action Replay) are applied by each core's own cheat engine — what works varies by system and isn't guaranteed. If a code glitches, disable it in the in-game cheat manager.

      📺 Display options

      CRT scanlines, integer scaling and aspect ratio for this system — remembered per system on this device. Reduced-motion safe: the tube flicker never runs when your OS asks for reduced motion, and panel animations are disabled.

      Also in the toolbar while playing, and in the quick-settings drawer. Integer scale snaps the picture to whole-pixel multiples — no blurry half-pixels. Aspect options reframe the engine's canvas with CSS; the emulated resolution never changes.

      » Netplay — the honest state

      • What it is: the EmulatorJS engine advertises a WebRTC room-code netplay feature (a host creates a room, others join with a code, inputs sync peer-to-peer). Both players need their own copy of the same game file — no file ever travels through us.
      • The honest state: the engine's own docs flag netplay as "being worked on" — historically it needed pre-4.0 builds, old cores, and a signaling server. Button Mash has not verified netplay end-to-end on the stable engine build, so it is not enabled or promised here. Expect latency; not every core or game behaves.
      • If you try it elsewhere: same file on both ends (dumped from hardware you own), a decent connection, and low expectations for twitchy games. For local multiplayer, two gamepads on one machine in this Player works today.

      » How to play

      1️⃣

      Load your file

      Drag & drop, pick from your device, or paste a direct download URL (the host must allow cross-origin fetches — if a URL fails, download it and drop it in). The system is auto-detected from the file extension; override it with the dropdown if needed.

      2️⃣

      Control it your way

      Keyboard works out of the box — arrow keys and the usual suspects cover most games. The Controls tool shows Player 1's keyboard + gamepad bindings and lets you remap them, one map per system (applies on next boot; Esc cancels a remap). USB gamepads are supported, and touch devices get on-screen buttons automatically.

      3️⃣

      Save like it's 1999 (but better)

      Save states live in the in-game menu: by default they download as .state files; switch to Keep in Browser in the engine's Settings → Save States and the Save slots tool gives every game named slots — save, restore, rename, export, import, delete — plus an auto-save timer. Everything is browser-local; export the file to move a save to another device. In-game saves (SRAM) work too. Ejecting swaps the cartridge — your slots stay put.
