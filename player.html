Player tools

Everything below runs in your browser. Your files, saves, and settings never leave your machine.

Save slots

Named save slots for the current (or most recent) game, kept in this browser's storage, the same place the engine's Keep in Browser mode uses. Save copies the engine slot into a named slot; Restore copies it back so the engine's Load State picks it up. Slots are browser-local, so export the file to move one to another device.

Boot a game above to manage its save slots.
    Auto-save

    Import writes the file into browser storage under the current game's name, so the engine's Load State picks it up. State files are tied to the emulator build; a file from a much newer or older engine may not load. Auto-save copies the engine slot on a timer while this tab stays open, and only works in Keep in Browser mode (in-game menu, Settings, Save States).

    Controls, per-system remap

    Player 1's keyboard and gamepad bindings, one map per system: remap GBA once and every GBA game uses it. Click Remap key, then press a key (Esc cancels); click Remap pad, then press a gamepad button. Saved maps apply the next time a game for that system boots. The remapper is fully keyboard-operable.

Analog-stick axes can only be remapped in the engine's own Control Settings (gamepad icon in the in-game menu). Older per-game mappings were moved into the per-system map automatically.

    Cheats

    Enter your own cheat codes for the current game. They load into the engine's cheat manager when the game boots; toggle them with the cheat icon in the in-game menu. Use codes you trust, for games you own.

    Boot a game above to attach cheats to it.

      Code formats (Game Genie, GameShark, Action Replay) are applied by each core's own cheat engine; what works varies by system and is not guaranteed. If a code glitches, disable it in the in-game cheat manager.

      Display options

      CRT scanlines, integer scaling, and aspect ratio for this system, remembered per system on this device. Reduced-motion safe: the tube flicker never runs when your system asks for reduced motion.

      Also in the toolbar while playing, and in the quick-settings drawer. Integer scale snaps the picture to whole-pixel multiples, no blurry half-pixels. Aspect options reframe the engine's canvas with CSS; the emulated resolution never changes.

        Netplay, the honest state

        • What it is: the EmulatorJS engine advertises a WebRTC room-code netplay feature: a host creates a room, others join with a code, inputs sync peer to peer. Both players need their own copy of the same game file; no file ever travels through us.
        • The honest state: the engine's own docs flag netplay as "being worked on"; historically it needed older builds and a signaling server. PortPlay has not verified netplay end to end on the stable engine build, so it is not enabled or promised here. Expect latency; not every core or game behaves.
        • What works today: local multiplayer, two gamepads on one machine in this Player. For online play, both players load their own dumps of the same game in an engine that supports it natively.
